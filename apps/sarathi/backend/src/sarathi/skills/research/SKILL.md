# Research

Use the research level named in the task. If the task omits a level, use `normal`.

When delegating research, include the requested `shallow`, `normal`, or `deep` level in the child task. Omit it only when `normal` is intended.

- `shallow`: Make one focused search pass and aim for 2–3 strong sources.
- `normal`: Search from multiple query angles, aim for 4–6 useful sources, and cross-check important claims.
- `deep`: Decompose the question, run follow-up searches, prefer primary sources, aim for at least 8 useful sources when available, and resolve contradictions or report the gaps.

These are effort targets, not quotas. Stop when more searching has low expected value or the turn limit is near.

At every level:

- Cite every URL actually consulted.
- Separate confirmed findings from inference or uncertainty.
- State material limitations, unresolved contradictions, and missing evidence.
